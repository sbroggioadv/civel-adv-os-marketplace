Plugin Claude Code de **contencioso civel brasileiro** (Civil Litigation Master), de uso nacional.

## Instalacao (Claude Desktop)
1. Settings -> Plugins -> aba Pessoal -> "+" Adicionar marketplace.
2. Cole a URL deste repositorio. Sincronize e instale **civel-adv-os**.
3. Rode **`/start-civel`** para configurar.

Procedimento comum + tutelas + recursos + gestao processual transversal. 64 skills, orquestrador `civel-master`, Suprema Corte R1-R4. Fundacao: CPC/2015 + CC/2002 + reformas + jurisprudencia.
